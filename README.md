# WG0 charter: Use Cases and Terminology (UCT)

*Working title and acronym — open for revision.*

Charter of Working Group 0 of the ITU-T Focus Group on Trust and Identity for Humans and Agentic AI (FG-TIDA).

WG0 maintains the shared terminology and the shared use-case register that every other FG-TIDA Working Group relies on.

**Status:** draft, initial proposal for discussion.
The Working Group is provisional until FG-TIDA approves it at its first meeting in Paris (30 November to 1 December 2026).

📄 [Web page](https://fg-tida-wg0.github.io/wg0-uct-charter/) · 📑 [PDF](https://fg-tida-wg0.github.io/wg0-uct-charter/wg-charter.pdf)

## Contributing

The charter text is [charter.md](charter.md), the single source of truth.
Every push to `main` generates the template's `src/doc/index.rst` from it and publishes the web page and PDF.
Open an issue for questions and proposals, or a pull request for concrete text changes, as described in [CONTRIBUTING.md](CONTRIBUTING.md).
Please do not push to `main` directly.

The template's authoring guide is [WG-ONBOARDING.md](WG-ONBOARDING.md).
Where it says to edit `src/doc/index.rst`, edit `charter.md` instead.
